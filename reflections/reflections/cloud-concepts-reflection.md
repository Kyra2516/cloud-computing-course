Using cloud services really helps me in my daily life, especially when it comes to my school-related tasks. They make it easier for me to store files, communicate with others more conveniently, and complete different activities efficiently. The three cloud services that I use most often are Messenger, Google Drive, and Canva. Messenger allows me to communicate with my classmates, instructors, friends, and family anytime and anywhere. Google Drive helps me store important files, especially school-related documents, and keeps them organized so I can easily access them from any device whenever I need them. Lastly, Canva helps me create presentations, posters, and other school projects more easily. Overall, these applications save me time, improve my productivity, and make my daily tasks easier to accomplish.

The three services that I listed are all classified as Software as a Service (SaaS) because I access them through the internet without having to install, manage, or maintain the underlying servers and infrastructure. They also use the Public Cloud deployment model because they are available to anyone who creates an account and has an internet connection. I chose this classification because Google Drive securely stores my files online, Canva provides online design tools that I can use from different devices, and Messenger allows me to send messages, make calls, and share files instantly through cloud-based services.

Moreover, version control is essential when working with cloud infrastructure because it records every change made to files and allows previous versions to be restored if a mistake occurs. Git and GitHub help teams collaborate by enabling multiple members to work on the same project while keeping track of who made each change. This reduces the risk of overwriting files, prevents errors, and keeps cloud resources well organized. By using GitHub, developers can manage projects more efficiently, work together effectively, and maintain a complete history of changes throughout the development process.
